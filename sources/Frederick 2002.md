# Frederick 2002: Automated choice heuristics
## Summary

[[Frederick 2002]] is a useful bridge source between [[Heuristics and Biases]] and [[Fast and slow thinking]]. Its central contribution is to argue that some heuristics should be understood not only as crude shortcuts but as automated choice procedures that can be triggered quickly and operate with little reflective supervision.

In the current vault, this source matters because it sharpens the fast-and-slow page from inside the heuristics tradition itself. It supports a more structured picture in which intuitive processing is not merely error-prone guessing, but can involve routinized and relatively stable choice procedures.

## Key claims

The first claim is that some heuristics are better described as automated procedures than as isolated one-off biases. They can function like default response rules in recurring environments.

The second claim is that automaticity is compatible with structure. A heuristic can be fast and low-effort without being psychologically uninteresting or theoretically shallow.

The third claim is that this matters for the interpretation of behavioral evidence. In the current vault, it helps explain why dual-process contrasts should not reduce the fast side of cognition to noise or blind impulse.

## Why it matters for fast and slow thinking

This chapter belongs in [[Fast and slow thinking]] because it gives that page a narrower and more behavioral-economics-facing mechanism source. [[Sloman 1996]] gives the large computational contrast between associative and rule-based reasoning. [[Frederick 2002]] matters because it shows how a heuristic can itself be procedural and automatic.

That makes the source useful against overly simple textbook formulas. If heuristics can be automated procedures, then the contrast between fast and slow reasoning is partly about which procedure is activated, not only about whether one is thinking hard enough.

## Why it matters for PPE

For PPE students, this source matters because it shows a common maturation pattern in the literature: the same empirical regularities can be redescribed at a more psychologically informative level. It matters for economics because models of bounded or intuitive choice often need some account of what the chooser is actually doing. It matters for philosophy because it complicates the inference from automaticity to irrationality. It matters for politics because institutional design often interacts with preexisting routines rather than with fully reflective choice from scratch.

## Links into the wiki

The main target is [[Fast and slow thinking]]. The source also strengthens [[Heuristics and Biases]] by showing that later developments in the program are not only about adding more biases, but also about clarifying how intuitive procedures operate.

## Open questions

How stable are automated choice heuristics across tasks and domains? When does routine improve performance, and when does it lock in poor judgment? And how should this branch connect to later work on cognitive reflection and decision automation?
