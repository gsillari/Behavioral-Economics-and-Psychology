# Cognitive Architectures of Judgment

## Scope

This topic will gather the main psychological architectures used to explain behavioral findings about judgment and inference. In the current vault, the key entry points are [[Sloman 1996]], [[Fast and slow thinking]], [[Logical intuitions]], and [[Heuristics and Biases]].

The purpose of this branch is to move from benchmark failure to process explanation: not just that people diverge from formal norms, but how those divergences arise in actual cognition.

The topic page is being used as a structural placeholder so the parent page [[Foundations and Rationality]] reads as a hub of links rather than a long embedded outline. A later drafting pass should integrate the Sloman, Evans, De Neys, Kahneman, and Tversky branches into one readable account for first-year PPE students.
